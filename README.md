# 🎯 Student Placement Prediction & Career Intelligence Platform

A machine learning application that predicts student placement probability and provides career readiness insights through skill analysis, ATS evaluation, and personalized recommendations.



## Preview

> <img width="1536" height="1024" alt="placement" src="https://github.com/user-attachments/assets/db6824e6-c54a-41f3-ab97-1d70ded91839" />




## Key Features

- Placement Prediction using Random Forest
- Career Readiness Assessment
- ATS Readiness Score
- Skill Gap Analysis
- Career Fit Evaluation
- Personalized Action Plan
- Interactive Streamlit Dashboard



## Tech Stack

| Category | Technologies |
|----------|--------------|
| Machine Learning | Scikit-learn (Random Forest) |
| Backend | Python |
| UI | Streamlit |
| Data Processing | Pandas, NumPy |

## Quick Start

```bash
git clone https://github.com/nithu0035/Student-Placement-Prediction.git

cd Student-Placement-Prediction

pip install -r requirements.txt

streamlit run app.py
```
